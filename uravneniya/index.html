Свои уравнения

Одно уравнение на строку. Можно писать так: 5x + 3 = 28, 72 : x = 8, (x − 4) · 3 = 15, x + 2,5 = 7, x − 3/8 = 1/8, 2 1/3 + x = 5. Умножение — * или ·, деление — :. Ответ считается сам.
